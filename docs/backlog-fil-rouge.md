# Backlog fil rouge

Ce backlog transforme le projet en progression de formation.

## Episode 1 - Lire le systeme

Objectif : comprendre le pipeline existant.

Livrables :

- Schema du flux actuel.
- Liste des entrees, sorties et dependances.
- Identification des zones fragiles.

## Episode 2 - Separer les couches de contexte

Objectif : distinguer role, mission, format, contraintes aval et evaluation.

Livrables :

- Carte de contexte completee.
- Prompt metier annote.
- Contrat de sortie explicite.

## Episode 3 - Stabiliser le contrat JSON

Objectif : rendre la sortie exploitable par du code.

Livrables :

- Validation stricte des champs attendus.
- Messages d'erreur actionnables.
- Exemple de JSON minimal valide.

## Episode 4 - Evaluer avant de publier

Objectif : eviter de publier une formation mediocre ou invalide.

Livrables :

- Checklist qualite.
- Commande de validation locale.
- Rapport simple par chapitre.

## Episode 5 - Industrialiser le pipeline

Objectif : passer d'un script unique a des etapes controlables.

Livrables :

- Commande de generation seule.
- Commande de validation seule.
- Commande de publication seule.
- Sorties horodatees ou nommees par scenario.

## Episode 6 - Generaliser a un autre sujet

Objectif : tester si l'architecture tient quand le domaine change.

Livrables :

- Nouveau prompt metier.
- Comparaison des resultats.
- Ajustement du contrat si necessaire.
