# Workflows

Ce dossier decrit les procedures operationnelles du projet.

Difference avec `docs/workshops/` :

- `docs/workshops/` sert a apprendre et animer des ateliers.
- `workflows/` sert a executer une tache du projet pas a pas.

## Workflows disponibles

- `generation-moodle.md` : generer et publier une formation dans Moodle.
- `validation-locale.md` : verifier le projet sans appeler OpenAI ni Moodle.
- `generation-google-docs.md` : utiliser la variante archivee vers Google Docs.
- `publication-github.md` : publier le projet sur GitHub sans exposer les secrets.
