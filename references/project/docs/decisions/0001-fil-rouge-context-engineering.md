# Decision 0001 - Structurer le projet comme fil rouge

## Statut

Acceptee

## Contexte

Le projet contient deja un pipeline fonctionnel de generation Moodle, mais il manque une structure pedagogique pour l'utiliser comme support de formation sur le context engineering.

## Decision

Ajouter une couche documentaire et contractuelle sans deplacer les scripts existants.

La structure introduit :

- une carte d'architecture ;
- une carte des couches de contexte ;
- un contrat de sortie JSON ;
- une checklist qualite ;
- un backlog de progression ;
- des ateliers pratiques.

## Consequences

Le projet reste executable comme avant, mais il devient aussi lisible comme support de cours. Les prochaines evolutions peuvent maintenant etre reliees a un objectif pedagogique precis.
